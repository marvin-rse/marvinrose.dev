# marvinrose.dev

Source of [marvinrose.dev](https://marvinrose.dev), my blog about Microsoft Sentinel, Defender XDR, Entra ID and KQL.

Built with [Hugo](https://gohugo.io/) and the [Blowfish](https://blowfish.page/) theme, deployed to GitHub Pages.

## Run locally

Requires Hugo extended 0.164 to 0.167.

```bash
git clone --recurse-submodules https://github.com/marvin-rse/marvinrose.dev.git
cd marvinrose.dev
hugo server -D
```
